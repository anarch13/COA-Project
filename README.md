# Optimizing Heat 3D Algorithm using DOACROSS parallelism in OpenMP and other parallelism methods

The heat 3D algorithm, often used in scientific and engineering applications, solves the heat equation for a three-dimensional object describing how heat diffuses through a medium over time. This project implements the heat 3D algorithm and uses various parallelism methods like DOACROSS parallelism in OpenMP, wavefront parallelism and SIMD parallelism to optimize the performance.
